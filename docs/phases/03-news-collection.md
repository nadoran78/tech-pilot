# Phase 3: AI Technology News Collection

- **Status:** Draft
- **Applies to:** Phase 3
- **Purpose:** 신규 AI 기술 발표를 발견하고 원본 근거와 함께 축적하는 단계의 경계를 정의한다.
- **Read when:** 뉴스 수집 요구사항을 논의하거나 3단계 전환을 검토할 때
- **Related documents:** [문서 인덱스](../INDEX.md), [제품 로드맵](../product/roadmap.md), [2단계 문서](02-tech-stack-selection.md)

## Goal

새로 발표되는 AI 기술을 갈무리하여 이후에 검색, 요약하고 개인 연관성을 분석할 수 있는 신뢰 가능한 자료 기반을 만든다.

이 단계에서는 많은 출처를 무리하게 지원하는 것보다 출처 추적성, 반복 가능한 수집과 기본적인 중복 방지를 우선한다.

## In Scope

- 합의된 초기 출처에서 신규 항목 발견
- 제목, 대표 원본 URL, 출처, 발표 시각과 수집 시각 등 최소 메타데이터 보존
- 동일 URL, 외부 ID 또는 콘텐츠 기반의 기술적 중복 방지
- 수집 결과의 저장과 기본 조회
- 출처별 성공, 실패와 수집 결과 확인
- 새 출처를 추가할 수 있는 수집 경계 정의
- 실제 네트워크와 분리된 핵심 수집 테스트

## Guiding Constraints

- 확인 가능한 원본 출처를 보존한다.
- 공식 피드나 API가 있으면 임의의 HTML 접근보다 우선 검토한다.
- 원본 사실과 생성·추론된 데이터를 구분한다.
- 반복 실행으로 같은 항목이 계속 생성되지 않게 한다.
- 한 출처의 실패가 다른 출처의 수집을 막지 않게 한다.
- 이용 약관, 라이선스, 요청 제한과 비밀 값 안전을 고려한다.

세부 데이터 필드, 출처 우선순위, 재시도 정책과 어댑터 인터페이스는 이 문서에서 미리 확정하지 않는다.

## Non-Goals

- 사용자의 프로젝트와 학습 목표에 대한 영향 평가
- 수익화 가능성과 도입 우선순위 점수화
- 의미가 같은 여러 기사와 발표의 정교한 사건 통합
- 고급 요약·분류 파이프라인
- 자동 뉴스레터, SNS 또는 메신저 발행
- 복잡한 대시보드와 다중 사용자 권한 체계
- 사용자 프로젝트 저장소의 자동 수정

## Expected Deliverables

- 합의한 초기 출처를 처리하는 수집 흐름
- 저장되고 조회 가능한 최소 뉴스 데이터
- 반복 수집과 일부 출처 실패를 검증하는 자동 테스트
- 수집 실행과 결과를 확인하는 최소 인터페이스
- 지원 출처, 알려진 한계와 운영 방법 문서

## Exit Criteria

- 설정된 초기 출처에서 신규 항목을 반복적으로 수집할 수 있다.
- 같은 항목의 재수집이 기본적인 중복 레코드를 만들지 않는다.
- 저장된 항목에서 원본 URL과 출처, 발표 시각의 유무, 수집 시각을 확인할 수 있다.
- 한 출처의 실패가 전체 수집을 중단시키지 않고 실패 이유를 확인할 수 있다.
- 핵심 정규화와 중복 방지 동작을 실제 네트워크 없이 검증할 수 있다.
- 새 출처를 기존 핵심 흐름의 대규모 수정 없이 추가할 수 있다.
- 실제 수집 결과를 사용자가 검토하고 4단계 진행 여부를 결정한다.
